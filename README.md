# 🏏 IPL Cricket Analytics Dashboard

## About the Project
This project is an interactive Power BI dashboard built to analyze historical IPL cricket data. The goal was to visualize team performances, identify top run-scorers, and understand wicket distribution.

## Tools & Skills Used
* Power BI
* Data Cleaning
* Data Visualization
* Dashboard Design (Professional Theme with Gold Accents)

## Key Metrics Analyzed
* **KPI Cards:** Total Matches, Total Innings, Total Runs Scored, and Total Wickets.
* **Column Chart:** Visualized total runs scored by each batting team.
* **Donut Chart:** Analyzed the types of dismissals (caught, bowled, run out, etc.).
* **Treemap:** Highlighted the top run-scoring batsmen in big visual blocks.
* **Interactive Slicer:** Added a filter to view data by bowling team.
